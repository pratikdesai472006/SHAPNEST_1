# PROJECT_MEMORY.md — SHAPNEST System Architecture & Context Log

## 1. Project Overview & Architecture
SHAPNEST is an ultra-low-latency, multi-node Bluetooth Low Energy (BLE) proximity and distance estimation tracking system.
- **Physical Nodes (ESP32-C3 Mini, RISC-V @ 160MHz):**
  - **Node 1 (Fan):** MAC `70:af:09:2a:d7:f0` (`COM6`), Tx: +9 dBm, Ref RSSI @ 1m: -59 dBm, $n$: 2.2
  - **Node 2 (Iron):** MAC `70:af:09:32:ed:28` (`COM7`), Tx: +9 dBm, Ref RSSI @ 1m: -59 dBm, $n$: 2.2
  - **Node 3 (Door):** MAC `70:af:09:2b:1e:58` (`COM5`), Tx: +9 dBm, Ref RSSI @ 1m: -59 dBm, $n$: 2.2
  - **Child Wristband:** MAC `ac:a7:04:d2:fc:84` (`COM9`), Tx: +9 dBm, continuous 100% duty cycle passive scanner + 25 ms interval 23-byte telemetry broadcaster (`0x02` frame).
- **Mobile Processing Node (Flutter Android App):**
  - Eliminates legacy ESP32-WROOM central bridge.
  - Directly scans 2.4 GHz BLE advertisements via `flutter_blue_plus`.
  - Operates in dual tracking modes:
    1. **Direct Mode:** Phone $\leftrightarrow$ Anchor Nodes direct distance estimation.
    2. **Wristband Mode:** Phone listens to Wristband telemetry (Wristband $\leftrightarrow$ Anchor Nodes).

## 2. Distance Measurement & Signal Conditioning Pipeline
Distance is derived via the Calibrated Log-Distance Path Loss Model:
$$d = 10^{\frac{A - \text{RSSI}}{10 \cdot n}}$$
where $A$ is the 1-meter calibrated reference RSSI (in dBm) and $n$ is the environmental path loss exponent.

### Signal Processing Pipelines:
1. **On-Node (Wristband Firmware):**
   - **Sanity Gate:** Discards RSSI outside $[-95, -20]\text{ dBm}$.
   - **Cycle-Isolated Window Buffer:** Fresh samples collected per window without cross-cycle pollution.
   - **In-Window Median Filter:** Suppresses multipath RF null spikes.
   - **Impulse Rejection:** Discards samples deviating $>15\text{ dBm}$ from median.
   - **Adaptive EMA:** $\alpha = 0.60$ on step change $>4\text{ dBm}$ (movement); $\alpha = 0.25$ when stationary.
   - **Bounds Clamping:** $[0.15\text{ m}, 8.00\text{ m}]$; sentinels for stale/offline ($0xFFFF$).
2. **On-Phone (Flutter Engine):**
   - **Sanity Gate:** Discards raw RSSI outside $[-100, -15]\text{ dBm}$.
   - **Compact 3-Sample Median Buffer:** Bidirectional step flush on $|raw - kalman| \ge 2.8\text{ dBm}$ (instantly flushes stale samples upon separation or approach).
   - **Dual-Regime 1D Adaptive Kalman Filter:**
     - Stationary: $Q=0.005, R=14.0$ (strong smoothing, no jitter).
     - Moving: $Q=0.60, R=0.80$ (highly responsive tracking).
     - Fast Attack: $Q=1.40, R=0.25$ (symmetric $K \approx 0.90$ for instant single-packet snap on separation or approach).
   - **Asymmetric Velocity Limiting:** Limits relaxed to $8.0\text{ m/s}$ and strictly restricted to `stationary` state so real physical motion is unconstrained.
   - **Hysteresis Dead-Band:** Zone-scaled $(2\text{ cm} - 10\text{ cm})$ to eliminate stationary numeric flicker.
